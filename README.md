# Aditya Kunjir — Developer Portfolio

Source for [adityakunjir.me](https://adityakunjir.me), a responsive portfolio presenting my full-stack, cloud, automation and product-development work.

## Highlights

- Project case studies for Stryk, Samaan and other production work
- Responsive desktop and mobile navigation
- Accessible keyboard interactions and reduced-motion support
- Project detail panels, media galleries and downloadable resume
- Open Graph preview metadata for link sharing
- GitHub Pages deployment through the repository's custom domain

## Technology

The site is intentionally framework-free and uses semantic HTML, CSS and JavaScript. Assets are optimized for static hosting on GitHub Pages.

## Run locally

Serve the repository with any static HTTP server. For example:

```bash
python -m http.server 8080
```

Then open <http://localhost:8080>.

## Project structure

```text
index.html   Page content and metadata
styles.css  Responsive layout, themes and motion
script.js   Navigation, project panels and interactions
assets/     Images, videos, icons and resume
CNAME       GitHub Pages custom domain
```
