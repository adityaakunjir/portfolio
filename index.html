01 // FEATURED PROJECT

Samaan — Hyperlocal Grocery Delivery Platform

A multi-role grocery delivery system connecting customers with nearby kirana stores. Includes Customer & Merchant apps with real-time order tracking, product management, and role-based access.

Built with ASP.NET Core (.NET 8) Web API, Entity Framework Core, Azure SQL, and JWT authentication. Deployed on Azure App Service with Swagger API documentation.

  • .NET 8
  • ASP.NET Core
  • JWT
  • Azure SQL
  • EF Core
  • Swagger
  • Azure
  • REST API

// SCREENSHOTS & FEATURES

Customer Authentication — Login & Onboarding

Secure authentication flow with email/phone login, demo credentials, OTP verification, and session-based access to personalized shopping and order history.

Product Discovery & Nearby Stores

Personalized home experience showing nearby kirana stores, categories, smart recommendations, and real-time delivery estimates.

Cart Management

Dynamic cart with quantity controls, pricing calculation, delivery fee logic, and promo code support.

Checkout & Payments

End-to-end checkout flow with address selection, order summary, and multiple payment options including UPI and credit card.

Order History & Tracking

Order lifecycle tracking with active and completed orders, reorder functionality, and real-time status updates.

Merchant Landing Page — Partner Onboarding

Public-facing merchant portal introducing the platform, benefits, and onboarding flow for local store partners before authentication.

Merchant Dashboard

Centralized dashboard for merchants to manage their store, view analytics, track revenue, and handle orders from a single view.

Product & Inventory Management

Merchant interface for managing product catalogue, stock levels, pricing, and availability with category-based organization.

Order Notifications & Management

Real-time incoming order alerts for merchants with accept/reject controls and order status progression workflow.
